# 일봉 RSI 매매 신호

일봉 종가 기준 RSI(Wilder 방식)로 매수 · 매도 · 관망을 판단하는 정적 웹페이지입니다. 서버 없이 `rsi/index.html`을 열면 동작합니다.

- **데이터**: 업비트(KRW 마켓), 바이낸스(USDT 마켓) 공개 API, 또는 일봉 CSV 업로드(주식 등, `Date`/`Close` 열 자동 인식)
- **판단 규칙** (기간·기준값 변경 가능, 기본 14 / 30 / 70)
  - RSI가 매수 기준을 상향 돌파 → **매수**, 매수 기준 미만 → **매수 관심**
  - RSI가 매도 기준을 하향 이탈 → **매도**, 매도 기준 초과 → **매도 관심**
  - 그 외 → **관망**
- **차트**: 종가 + RSI 패널, 백테스트 매수/매도 지점 표시
- **백테스트**: RSI < 매수 기준이면 종가 매수, RSI > 매도 기준이면 종가 매도 (수수료 반영), Buy & Hold 비교
- **관심목록**: 여러 종목의 현재 RSI/신호를 한 번에 확인 (브라우저에 저장)

> 참고용 지표이며 투자 권유가 아닙니다.
