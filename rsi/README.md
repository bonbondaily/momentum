# RSI 시그널

일봉 RSI로 주식의 매수 · 매도 · 관망을 판단하는 웹사이트입니다. 한국 주식(코스피·코스닥)과 미국 주식을 지원합니다.

## 실행

Node.js 18 이상이 필요합니다. 설치할 패키지는 없습니다.

```bash
cd rsi
node server.js
```

브라우저에서 http://localhost:3000 을 엽니다.

> 주식 시세(Yahoo Finance)는 브라우저에서 직접 받아올 수 없어서 `server.js`가 대신 받아 전달합니다. 그래서 `index.html`만 열어서는 동작하지 않습니다.

### 인터넷에 배포 (Vercel, 무료)

Vercel에서 이 저장소를 가져오고 **Root Directory**를 `rsi`로 지정하면 배포됩니다. `public/`은 화면, `api/`는 시세 서버 역할을 합니다.

## 판단 규칙 (설정에서 변경 가능, 기본 RSI 14 / 30 / 70)

| RSI | 판단 |
|---|---|
| 30을 아래에서 위로 돌파 | **매수** |
| 30 미만 | 매수 관심 |
| 70을 위에서 아래로 이탈 | **매도** |
| 70 초과 | 매도 관심 |
| 그 사이 | 관망 |

## 기능

- 종목 검색: 한글 이름(삼성전자), 종목 코드(005930), 미국 티커(AAPL)
- 관심종목: 종목별 RSI·신호를 한눈에 보고 매수/매도/관망으로 필터
- 캔들 차트 + RSI 차트, 매수·매도 신호 표시
- 백테스트: 최근 2년간 이 규칙대로 매매했을 때 수익률·승률 (수수료·세금 반영)

## 구조

```
rsi/
  server.js        로컬 실행 서버
  api/             시세·검색 API (Vercel 함수와 공용)
  lib/yahoo.js     Yahoo Finance 조회
  lib/stocks.js    한글 이름 검색용 주요 종목 목록
  public/          화면 (index.html, style.css, app.js, rsi.js)
```

RSI 지표만 기계적으로 적용한 참고 정보이며 투자 권유가 아닙니다.
